# TOKYO WALKER

デフォルメした東京を PS1 / N64 風の見た目で歩き回る、ブラウザ用の 3D 散歩シミュレーター (Three.js)。

## 遊び方

**ブラウザで遊ぶ: https://sonek-wq.github.io/tokyo-walker/** (GitHub Pages)

手元では `python3 build.py` で作った `dist/tokyo_walker.html` をブラウザで開くだけです (1ファイルで完結。Three.js は CDN から読み込みます)。GitHub Pages 用には同じものを `docs/index.html` に置いています (ソースを変えたら `python3 build.py` のあと `cp dist/tokyo_walker.html docs/index.html`)。

名所に入ると、名前の下に短い豆知識 (💡 へぇ！と思える話) が出ます (🧭 役立ち情報 `LM_TIPS` は表示をやめた。データは残っていて、`game/30_fun.js` の `SHOW_TIPS` で戻せる)。
一度読んだものは **K の豆知識帳** にたまっていきます (同じ場所の豆知識は90秒のあいだ出さない)。
E キーで乗り物に乗るほか、おみくじを引いたり、エレベーターで展望台へ上がったりできます。

- M の全体マップは、マウスホイールか ＋ / − キーで5段階に拡大縮小できる (拡大すると現在地を中心に、道路や建物まで描いた細かい地図になる)
- 全体マップを開いている間はマウスが自由に動く。地図の外側 (暗いところ) をクリックするか、もう一度 M を押すとプレイに戻る
- F でファストトラベル (テストプレイ用): 山手線・ほかの路線・ゆりかもめ・水上バスのどの駅へも一瞬で移動できる。駅名を打って絞り込み、Enter で先頭の駅へ。緑の枠は駅のまわりを作り込み済みの駅 (エリアのファイルの `stations: [...]` で宣言する)
- ハンググライダーは、足もとの地面や屋上から2m以上の高さでないと開けない (平らな地面でジャンプしても約1.1mなので開かない。階段や塀の上からなら開ける)
- 壁に向かって歩くと登れる (登る速さは歩く速さの半分)

## ビルド

```
python3 build.py          # dist/tokyo_walker.html を作る
python3 build.py --zip    # ソース一式の zip (dist/tokyo_walker_src.zip) も作る
```

`src/` のファイルを `src/build_order.txt` の順に1つの `<script type="module">` へつなげ、
`src/index.template.html` に埋め込みます。Python 3 だけで動きます (追加のライブラリは不要)。

## フォルダ構成

| 場所 | 中身 |
| --- | --- |
| `src/index.template.html` | 画面の HTML と CSS。スクリプトは `/*@@BUNDLE@@*/` の位置に入る |
| `src/engine/` | エンジン: 描画・当たり判定・地面・建物の組み立て・山手線の環と列車・自動生成の街・地図・プレイヤー・時間など |
| `src/areas/` | 作り込みエリア: 竹芝・浜松町・芝・東京タワー・新橋・汐留・銀座・築地など |
| `src/stations/` | 山手線の駅 (1駅 = 1ファイル、JY番号順) |
| `src/regions/` | 山手線の外・東側のエリア (`00_geography.js` に海岸線・島・川・橋・水上バス、ほかはエリアごとのファイル) |
| `src/game/` | 遊びの要素 (アルバムと豆知識帳は外側をクリックしても閉じる): うんちく・ねこ・実績・じいちゃんの写真・到着/出航の演出・メインループ |
| `build.py` | 1ファイルの HTML にまとめるスクリプト |

## デフォルメのルール

- 建物・道幅・名所の大きさは実寸のまま
- 場所と場所の間は実際の約 1/2 (浜松町駅を基準に緯度経度を縦横 1/2 に縮めて配置)
- 山手線の環は実際の形・駅の順番・方角を保つ (1周 約17km)
- 浜松町〜新橋の間だけは、作り込み済みの街並みを残すため南北を少し伸ばしている
- 東側: 隅田川沿い (浅草・両国・清澄) は山手線と同じく約1/2。湾岸の埋立地は竹芝・築地に合わせて配置し、荒川より東は東西を約1/4に縮める
- 川は折れ線に幅をつけた形で、川の中だけ地面を掘り下げて水面を見せる。橋は船がくぐれるよう中央が高い
- 川に `autoBridges: 名前` を書くと、100mごとの道路と交わるところに自動で橋がかかる (目黒川)

- 東京モノレールは浜松町と天王洲アイル (京浜運河の上の駅) の間を往復する (乗れない)

エリアの名所は各ファイルの `build(r)` に書き足していく (駅ファイルと同じ道具が使える)。

## 駅を作り込むには

`src/stations/jyNN_xxx.js` の `build(st) {}` の中に、その駅ならではの建物や名所を書きます。
駅舎・ホーム・駅名標・駅前広場は共通の仕組みで自動的に作られます。
`st.x, st.z` が駅の位置、`ringAt(st.s)` で線路の向き (`tx, tz`) と外向きの向き (`nx, nz`) が取れます。

名所づくりの道具は `src/engine/11b_landmark_kit.js` にあります。

- `custom: true` … 共通の駅舎を作らず、駅舎も `build(st)` で作る (入口は `st.ent` / `st.ents`)
- `land` … お濠などの水面 (`water`)・橋 (`bridges`)・歩ける場所 (`walk`) を指定する (関数にすると線路の位置から計算できる)
- `frame()` … 線路の向きに合わせて回転した座標系。`oBox` / `oHip` / `oTiles` / `oRoad` で回転した建物・屋根・地面を作る
- `LM_ZONES` … 自動生成の街を置かない範囲 / `addRoads()` … 車の走る道路 (信号・街路樹も自動)
- `LM_UPDATERS` (毎フレームの動き)・`LM_ACH` (実績)・`LM_NOTES` (豆知識)・`LM_TIPS` (役立ち情報。いまは表示しない)・`LM_CATS` (ねこ)・`LM_LABELS` (地図)・`LM_PEOPLE` (歩く人。道の端の座標の後ろに高さを書くとデッキの上を歩く)・`ROAD_STOPS` (車が止まる信号)
- `stnFrame(駅名)` … 山手線の駅にそろえた座標系 (u = 線路の向き、v = 環の外向き)。`shopsAlong` (看板つきの店並み)・`roofLift` (屋上へのエレベーター)・`rotSpots` (回転した名所の名前)・`oRampV` (上れるスロープ) と組み合わせて使う
- `LM_ACTIONS` … E で使う仕掛け `{ at, prompt, act }` (おみくじ・エレベーターなど)。`lmWarp(x, y, z, yaw, msg)` で暗転して移動
- `LM_HEIGHT_AREAS` … 高さで決まる地名 (展望台など) `[名前, (x, z, y) => bool]`
- お寺・神社の道具: `jRoof()` (反った屋根)・`chochin()` (提灯)・`figure()` (像)・`myojinTorii()` (笠木が反った鳥居)
- `bake(材質, 形)` と `bakeFlush()`: 小さな飾りを1つの形にまとめて描画の回数を減らす
- `akRoad(始点, 終点, 幅, 名前)` (regions/06_akasaka.js): 斜めの道路を歩道・街路樹・歩く人つきで引き、道の名前も表示する。六本木でも使っている
- `HOKO_ZONES` (11b): 銀座以外の歩行者天国。`{ name, r, on }` を入れると、実施中はその車道の車が消え、エリア名が変わる。`LM_PEOPLE` の3番目に関数を入れると、その間だけ歩く人になる
- `regions/03_campus_kit.js`: `acGothic()` (尖ったアーチ窓の壁の柄)・`acStatue()` (台座つきの銅像)・`acRoad()` (歩道と街路樹つきの道路)・`acFree()` (建物と重ならない場所か調べる。木を植える前に使う)
- `bakeFlush()` は、まとめた形の中心をメッシュの位置にする (小さなまとまりは最後に「その場所のチャンク」に移されるので、原点に置いたままだと遠くで見えなくなる)
- `PONDS` (池: 歩いて入れない) と `POND_LAND` (池の中の島や橋など、歩ける場所)
- `SAKURA` … 桜の木 (春は花、秋は紅葉)。`REGION({ styles })` の `shitamachi` は低い家並みの下町

### 豆知識の書き方

- 豆知識 (`LM_NOTES`) は「へぇ！」と思える一言。長い歴史の説明は書かない (目安は全角50字くらいまで)
- 役立ち情報 (`LM_TIPS`) はいまは表示しない (`SHOW_TIPS = false`)
- 入場料・運賃・値段など、現実のお金の情報は書かない (遊んでいる人に現実のお金のことを思い出させないため)
- 営業時間・開館時間・休みの日・予約や申し込みの方法も書かない (現実の予定を気にせず歩けるように)。豆知識は建物や景色・歴史の「へー」で書く
- どちらも、公式サイトなどで確かめた事実だけを書く

新しい駅ファイルを足すときは `STATION({ no, name, kana, roma, town, lat, lon, build(st) {} })` を書いたファイルを
`src/stations/` に置くだけです (ビルド時に番号順で自動的に組み込まれます)。
